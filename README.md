# Lumi

Red social simple en Flutter, tema claro. Tres pantallas: Inicio, Explorar y Perfil.

## Qué incluye

- Inicio: feed de publicaciones **solo 1:1**, botón **+** arriba a la derecha (debajo de la barra de estado).
- El **+** abre una **galería interna** (no la app Galería del teléfono) con las fotos del dispositivo, las más recientes primero.
- Al elegir una foto: vista previa a pantalla completa, pie de foto y botón **Publicar** arriba a la izquierda.
- Al publicar, la foto aparece en tu Perfil y en el feed.
- Explorar: búsqueda de personas, nombres, temas, hashtags y frases.
- Perfil: avatar redondo. Si no hay foto, se usa el icono adjunto. Tocá el avatar para elegir una foto.

## Cómo correrla

```bash
cd nexo
flutter pub get
flutter run
```

Usá un teléfono Android o iOS real para probar la galería. En web/Linux la galería nativa no está disponible.
